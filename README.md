# 🎶Music Popularity Data Analysis 
Data analysis project using Python, Pandas, NumPy, Matplotlib, Seaborn and Jupyter Notebook to explore, analyze and visualize data

## 📌 Project Overview 

This project explores the relationship between different music variables and song popularity using python and Jupyter Notebook.

## 🔍 Project Objectives 

- Explore the music dataset using Python
- Analyze relationships between music variables
- Compare features such as loudness and energy with song popularity
- Create visualizations to better understand patterns in the data
- Practice interpreting results from explanatory data analysis

  Some of the variables include
  -🔈Loudness
  -⚡️Energy
  -🎧Tempo
  -🔑Key
  -🎶Genre

  ## 💡 Skills Demonstrated
  - Data cleaning
  - Exploratory Data Analysis
  - Data visualization
  - identifying relations between variables

    ## 📂 Project File
    The Jupyter Notebook included in this repository contains the python code, analysis, visualization, and results from the project.
